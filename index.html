Abonnement & Annulation

ParcelProof propose :

  • Version gratuite : jusqu'à 3 dossiers simultanés.
  • ParcelProof+ : dossiers illimités, exports ZIP/PDF, support prioritaire.

Annuler ou gérer votre abonnement :

  1. Ouvrez l'App Store sur votre iPhone/iPad.
  2. Appuyez sur votre profil (en haut à droite) > Abonnements.
  3. Sélectionnez ParcelProof puis Annuler l'abonnement.

Vous pouvez aussi utiliser le lien direct Apple : Gérer mes abonnements.

2. Collecte des données

ParcelProof est conçu pour respecter votre vie privée. Nous ne collectons aucune donnée personnelle sur nos serveurs.

  • Toutes vos vidéos, photos et dossiers sont stockés localement sur votre appareil.
  • Nous n'avons accès ni à vos vidéos, ni à votre caméra, ni à votre bibliothèque photo à distance.

3. Permissions iOS

L'application demande les permissions suivantes pour fonctionner :

  • Caméra : Uniquement pour filmer les preuves d'emballage/déballage.
  • Microphone : Pour enregistrer le son ambiant (optionnel) sur les vidéos.
  • Galerie Photo : Pour sauvegarder les dossiers exportés sur votre téléphone.

4. Services Tiers

Nous utilisons Apple StoreKit pour gérer les abonnements "Premium". Apple traite vos informations de paiement de manière sécurisée ; nous n'y avons pas accès.

5. Suppression des données

Puisque toutes les données sont stockées sur votre appareil, supprimer l'application supprime définitivement toutes vos données et vidéos ParcelProof. Aucune démarche supplémentaire n'est nécessaire.
